# La economía del entretenimiento: Netflix y tendencias globales

## Integrante
- Emilio Oropeza - 230300762

## Descripción
Dashboard hecho en React que analiza el catálogo de Netflix usando el dataset [Netflix Movies and TV Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows) de Kaggle.

La idea es ver las tendencias del entretenimiento digital: cuántos títulos hay por país, cómo han cambiado los lanzamientos por año, cuáles son los géneros y directores con más títulos, y si hay más películas o series.

Es un dashboard **estratégico**, pensado para ver tendencias a largo plazo.

## Tecnologías
- React
- PostgreSQL (Supabase)
- Python (pandas) para limpiar los datos
- Vercel para publicar

## KPIs
- Títulos por país
- Lanzamientos por año
- Top 5 géneros
- Top 5 directores
- Películas vs series
